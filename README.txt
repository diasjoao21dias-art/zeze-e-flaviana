CONVITE DIGITAL OLIVIUM — OSMAR & FLAVIANA

Este projeto NÃO é uma imagem. É um convite digital interativo em HTML/CSS/JavaScript, pensado primeiro para celular.

Informações usadas da prévia enviada:
- Casal: Osmar & Flaviana
- Versículo: “E, acima de tudo, tenham amor, pois o amor une perfeitamente todas as coisas.” — Colossenses 3:14
- Data: sábado, 24 de outubro de 2026
- Horário: 17:00h
- Cerimônia: Igreja Nossa Senhora de Fátima
- Recepção: Rua A, 65 — Boa Vista TV
- Observação: Cada um levar sua bebida alcoólica.

Recursos:
- Tela de abertura
- Animações de entrada
- Efeitos ao rolar
- Contagem regressiva
- Botão de localização
- Confirmação por WhatsApp
- Layout mobile-first
- Visual inspirado na prévia floral enviada, mas transformado em experiência interativa.

IMPORTANTE:
O número do WhatsApp não foi fornecido na prévia, então o botão usa um link genérico. Antes de publicar para cliente, substituir o link pelo WhatsApp correto.

Para testar corretamente:
1. Publique os arquivos em uma hospedagem (Render, Vercel, GitHub Pages etc.).
2. Não abra o index.html diretamente pelo gerenciador de arquivos do celular.
3. Abra o endereço HTTPS gerado pela hospedagem.
